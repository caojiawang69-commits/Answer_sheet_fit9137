Scenario

The provided PCAP file for Apollo node contains the network traffic sent and received by this node for a period of time. During this time a user on this node has visited the web server of the organisation (the node named Web in the diagram), the intranet server (the node named Intranet in the diagram), and the external web server (the node named External in the diagram). The user Sepehr has sent an email to another user within the organisation and has used ping command to test the connection with nodes Zeus and Hera.

答题格式
  • MAC：冒号分隔；IP：点分十进制
  • 32 位 raw 序号 / 确认号：8 位十六进制，不加 0x，前面的 0 不能省
  • 大小、端口、帧号：只写数字；URI 带 http://；邮箱不带 < >
  • 真考时要手动输入，不要复制粘贴

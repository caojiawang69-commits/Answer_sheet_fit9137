FIT9137 看题定协议

先看题目里的协议词，再决定用哪个过滤器。这里的题号对应第 1 套带练页。

1看要交什么

  • frame number → 交 No. 列的数字
  • IP address → 交 IP
  • MAC address → 交 MAC

2看题目里的关键词，选过滤器

题目里出现协议过滤器题
DHCP、Ack、router option、assigned to Apollo、subnet maskDHCPdhcp1.1–1.6

icmp.type == 0 回复		2.1–2.4

3自查：Protocol 列要和题目的协议词一致

找到那一行后看 Protocol 列。题目写 DNS，那一行就必须是 DNS。例：3.6 问 DNS response，答案是 396（DNS）；399 是 ARP，不对。

问 MAC 的两种题

某台机器的 MAC（MAC address of Zeus）：看 ARP 回答，Info 写着「它的 IP is at MAC」。题 3.4、3.5。

某一帧的 MAC（destination MAC of the frame carrying the GET）：先按协议找到那一帧，再展开 Ethernet II 读 Destination。发往外网时这个 MAC 是路由器的。题 5.6。

问 IP 的两种题

某服务器的 IP：去 DNS 应答里查名字后面的 IP。

option 给的 IP / 分给 Apollo 的 IP：去 DHCP ACK 里读对应的那一行（Router、Domain Name Server、Your (client) IP address）。

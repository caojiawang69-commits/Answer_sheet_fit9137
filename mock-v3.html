Network Traffic Analysis using Wireshark

To complete this part of the quiz you need the packet capture file apollo_eth0_practice_V3.pcap.

Scenario

The provided PCAP file for Apollo node contains the network traffic sent and received by this node for a period of time. During this time a user on this node has visited the web server of the organisation (the node named Web in the diagram), the intranet server (the node named Intranet in the diagram), and the external web server (the node named External in the diagram). The user Daniel has sent an email to another user within the organisation and has used ping command to test the connection with nodes Zeus and Hera. The network connectivity is shown in the following diagram.

练习用拓扑，结构与 2024 S1 真题一致；节点的地址都在 apollo_eth0_practice_V3.pcap 里。

答题格式
  • MAC：冒号分隔，如 aa:bb:cc:dd:ee:ff；IP：点分十进制
  • 32 位 raw 序号 / 确认号的十六进制：正好 8 位，不加 0x，前面的 0 不能省，如 0cef3c91
  • 大小、端口、帧号：只写数字
  • URI 写完整，带 http://；邮箱不带 < >
  • 不区分大小写；前后不能有空格；考试时要手动输入，不要复制粘贴
答题顺序建议
  1. 先做 Task 1 和 Task 2：7 个空，每个 5 分，共 35 分。主机信息表（DHCP、ARP、DNS）一次查完。
  2. 再做 Visiting a Web Server：23 个空，每个 2 分，共 46 分。先锁定那一条 TCP 连接（SYN 帧），后面全部在它上面读。
  3. 最后做 Sending an email：12 个空，每个 1 分。握手部分和上面完全一样，只是端口换成 25。
  4. 两道 True/False 先填：SYN 是客户端发给服务器的（True），SYN 会消耗一个序号（True）。注意选项顺序会变。
